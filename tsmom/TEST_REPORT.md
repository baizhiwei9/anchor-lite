## 一、口径

| 项 | 设定 |
|---|---|
| 标的池 | 13 只 ETF：510300、510500、510050、159915、159949、512880、512660、512010、513100、513500、159941、513030、159920 |
| 杠杆 | 1x，无杠杆，只多 + 空仓 |

| 信号 | 组合层信号矩阵（`stmom_4models_out/sig_*.npz`），T 日收盘生成、T+1 生效（`np.roll` 1 天） |

| 空仓收益 | 现金年化 2% |
| 成本 | 单边 5bp × 日度仓位变动（`cost_bp=5`） |
| 无前视 | 信号、regime、Tucker z 全部 shift 1 天 |

## 二、继承结构

```
TsmomEngine                # 引擎：数据、信号、regime、波动率目标、成本、指标
└── V1Ensemble             # V1 继承基线：0.7×MLP + 0.3×CNN，vol 15%
    ├── V5Vol18            # 只覆盖 vol_target = 0.18
    ├── V6Tucker           # 只开启 Tucker 闸门（z≥1.5 仓位×0.5、z≥2.5 清仓）
    └── V8RuleMix          # 只覆盖信号为 MLP 与规则A（13 池等权全仓）各半
```

V5 / V6 / V8 均不复制引擎逻辑，只覆盖类属性，计算路径与 V1 完全一致。

## 三、测试结果（含成本 5bp）

### 3.1 继承口径（V5/V6 使用 V1 的集成信号）

| V5 波动目标 18% | +101.8% | 16.7% | −3.6% | 2.14 | 67% |
| V6 Tucker 闸门 | +84.1% | 14.4% | −3.6% | 2.00 | 64% |
| V8 MLP 与规则A 各半 | +162.3% | 23.6% | −8.9% | 1.84 | 69% |

### 3.2 实验口径对照（信号回退纯 MLP，用于复刻叠加大实验数字）

| 组合 | 总收益 | 年化 | 最大回撤 | 夏普 | 胜率 |
|---|---|---|---|---|---|
| 参考 MP 基座（纯 MLP + vol15%，无成本） | +121.9% | 19.2% | −4.9% | 2.23 | 70% |

参考 MP 基座与原 STMOM 口径二（`stmom_optimize_report.html`）完全一致（+121.9%/19.2%/−4.9%/2.23），说明本分支引擎实现正确、口径未漂移。

## 四、结论

1. **V1 是四套里风险调整最优的基线**：回撤 −3.6%、夏普 2.15，年化 16.4%，牺牲约 1.3pp 年化换来回撤改善 1.4pp（相对纯 MLP + vol15% 的实验基线）。
2. **V5 在继承口径下几乎等同于 V1**（+101.8% vs +99.7%），因为集成信号本身的波动已经较低，把目标波动提到 18% 只多放了少量仓位；要复现实验阶段 19.1% 的效果，必须走 `V5Vol18MP`（纯 MLP 信号）。
3. **V6 的 Tucker 闸门在两种口径下都是负贡献**：继承口径 16.7%→14.4%（−2.3pp），实验口径 19.1%→15.2%（−3.9pp），回撤没有进一步改善（都是 −3.6% / −5.0%）。
4. **V8 收益最高但风险显著放大**：年化 23.6%、回撤 −8.9%；且 2024/2025 两年 34.9%/34.9% 的收益来自混入的规则 A（13 池等权全仓），不是 MLP 的贡献，不能当作模型增强。

## 五、限制

- 四套组合是在 2022–2026 回测段上确定的，选优本身构成样本内挑选，存在过拟合风险；未做逐年留一或 2013–2021 的独立样本外验证。
- 信号与次日收益相关系数≈0（±0.03），收益主要来自 regime 闸门 + 波动率目标的仓位节奏，不宜解读为模型预测能力。
- 成本按单边 5bp 近似，未建模冲击成本、ETF 折溢价、申赎限制；换手估计包含仓位缩放但未单独拆分 regime 切换的冲击。
- 数据为场内 ETF 收盘价（非指数点位、非成分股），分红与折溢价未单独处理。
- 本分支 `assets/` 内固化的是 13 池收盘面板与四模型信号矩阵快照（截至 2026-09-22），不含 Tick、分钟级与实时数据；要向前推进需替换同名资产文件。
