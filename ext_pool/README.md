# anchor-tsmom_ext — 扩展池与 5% 回撤约束

本分支从 `main`（`f6e3010`）拉出，独立于 `Anchor-tsmom`，只放**扩展池（行业/宽基 ETF + 原油/黄金/美债/纳指/豆粕）在 5% 回撤约束下的回测代码与说明测试报告**。

## 内容

| 路径 | 说明 |
|---|---|
| `ext_pool/engine.py` | 扩展池规则动量引擎（22 只标的、截面 z-score、TopK 等权） |
| `ext_pool/engine_hybrid.py` | 核心信号 + 卫星趋势两层结构引擎（含宏观闸门开关） |
| `ext_pool/make_report.py` | 报告生成器（读 `out/` 快照，输出内联 SVG 的对比报告） |
| `ext_pool/out/` | 结果快照：`metrics_opt.json`、`results_ext.json`、`results_leg.json`、`nav_*.csv` |
| `ext_pool/扩展池与5%回撤约束对比报告.html` | 说明测试报告（自包含、离线可读） |

## 口径

- 区间：2022-01-04 ~ 2026-09-22（主窗口，1145 个交易日）；扩展B 短窗 2025-01-02 ~ 2026-09-22
- 频率与执行：日频、T 日信号 T+1 生效、只多 + 空仓、1x 无杠杆、单边 5bp 成本
- 风控：regime 等权净值 MA200 闸门 + 波动率目标（EWM60）+ 3% 回撤熔断
- 核心信号：既有 `sig_MLP.npz` / `sig_CNN.npz`（0.7/0.3 集成，13 池），本轮不重训
- 卫星：原油 501018、黄金 518880、10 年国债 511260、低波 512890、纳指 513100；扩展B 另含豆粕 159985、半导体/新能源/军工/医药行业 ETF
- 卫星规则：价格 > MA60 才持有，按 60 日波动率倒数加权，日频再平衡

## 复跑

```bash
export PYTHONPATH=<workspace>/py_deps
cd ext_pool
python engine_hybrid.py     # 核心+卫星两层结构网格
python make_report.py       # 由 out/ 快照重出报告
```

注意：`engine.py` / `engine_hybrid.py` 中的路径常量指向本机工作区，迁到别处运行时需改 `WS`、`A`、`L`、`OUT` 四个路径。

## 限制

- 主窗口止于 2026-09-22，因核心信号矩阵末日为该日；行情数据到 2026-11-06，延长需重算信号。
- 豆粕与行业细分 ETF 只从 2025-01 起有数据；行业池 `pool_rules71` 缺失率 47%，无法用于长窗口。
- 宏观闸门（PMI/CFNAI/美国衰退/QVIX）实测为负贡献，未纳入最优档。
- 3% 熔断在本区间未触发；回撤控制由波动目标与低波卫星完成。
- 参数（核心权重、目标波动）在 2022–2026 上网格选出，属样本内挑选，存在过拟合风险。
- 成本仅计单边 5bp，未建模冲击成本与 ETF 折溢价。
